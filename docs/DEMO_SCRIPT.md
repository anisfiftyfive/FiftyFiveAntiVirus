# Five-minute demo script

0:00–0:40 — Problem: people install apps without seeing what those apps can do, and Play Protect is opaque.

0:40–2:10 — Product: open DroidSentinel, show the shield, scan installed apps, open a finding with evidence, pick an APK if time allows. Point at honest statuses (database unavailable vs no match).

2:10–3:20 — AI workflow: show `AGENTS.md`, `.cursor/rules`, hooks, and `docs/AI_DECISIONS.md` (README vs source mismatch on Hypatia).

3:20–4:20 — QA: run or show `./gradlew testDebugUnitTest`. Highlight that a missing database is not a clean scan.

4:20–5:00 — Limits: BloomFilter possible matches, no real-time protection, AGPL because of Hypatia, next step is broader signature coverage and Play declaration for `QUERY_ALL_PACKAGES`.
